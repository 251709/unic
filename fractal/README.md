Описание проекта

Программа представляет собой визуализацию фрактального дерева с использованием библиотеки tkinter. Дерево строится с помощью рекурсивного алгоритма: от каждой ветви создаются две дочерние ветви меньшего размера, расположенные под заданным углом.

Программа также предусматривает возможность интерактивного изменения параметров его отображения.

Функциональные возможности

Основной функционал

* Рекурсивная отрисовка фрактального дерева
* Построение дерева по итерациям
* Настройка угла ветвления
* Графический интерфейс на основе tkinter

Дополнительный функционал

* Интерактивное изменение угла ветвления с помощью слайдера

Требования к системе

* Python: 3.9 или выше
* Операционная система: Windows / macOS / Linux
* Графическая библиотека: tkinter
* Дополнительные библиотеки: не требуются

tkinter входит в стандартную поставку Python и отдельно устанавливать его через pip не требуется.

Установка и запуск

1. Клонирование репозитория

git clone https://github.com/251709/unic.git
cd fractal

2. Создание виртуального окружения

Создание виртуального окружения:

python3 -m venv venv

3. Активация виртуального окружения

macOS / Linux

source venv/bin/activate

Windows

venv\Scripts\activate

4. Установка зависимостей

Для проекта используются только стандартные средства Python и tkinter, поэтому установка сторонних библиотек не требуется.

При наличии файла requirements.txt:

5. Запуск программы

python main.py

Управление программой

* Слайдер угла — изменение угла ветвления дерева

Алгоритм работы

Фрактальное дерево строится рекурсивно.

1. Из нижней части экрана проводится основной ствол дерева.
2. От конца текущей ветви создаются две новые ветви.
3. Левая и правая ветви отклоняются от текущего направления на заданный угол.
4. Длина новых ветвей уменьшается относительно длины родительской ветви.
5. Для каждой новой ветви алгоритм повторяется рекурсивно.
6. Рекурсия прекращается после достижения заданного количества итераций.

Для построения дерева используется около 10 итераций, что соответствует условию лабораторной работы.

Особенности реализации
