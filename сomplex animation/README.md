# Алгоритмы поиска кратчайшего пути

Проект реализует алгоритмы поиска пути в сеточном лабиринте с визуализацией процесса поиска.
В качестве графического интерфейса используется библиотека **Tkinter**.

## Возможности

- загрузка лабиринта из внешнего текстового файла;
- визуализация лабиринта в виде сетки;
- поиск кратчайшего пути с помощью алгоритма **A**;
- визуализация посещённых и текущих клеток;
- отображение найденного пути;
- реализация других алгоритмов поиска пути;

## Используемые алгоритмы

В проекте планируется реализовать:

- **A** — алгоритм поиска кратчайшего пути с использованием эвристической функции;
- **BFS** — поиск в ширину;
- **DFS** — поиск в глубину.

## Формат лабиринта

Лабиринт хранится во внешнем текстовом файле.

Используются следующие обозначения:

- `#` — стена;
- `.` — свободная клетка;
- `S` — начальная клетка;
- `E` — конечная клетка.

Пример:

```text
####################
#S.................#
#.################.#
#.................E#
####################
```

## Визуализация

Во время работы алгоритма клетки сетки окрашиваются разными цветами:

- **стена** — закрытая клетка;
- **посещённая клетка** — клетка, которая уже была исследована алгоритмом;
- **текущая клетка** — клетка, которая рассматривается в данный момент;
- **путь** — клетки найденного кратчайшего пути;
- **S** — начальная клетка;
- **E** — конечная клетка.

## Запуск проекта

Для запуска проекта необходимо установить Python и создать виртуальное окружение.

### Создание виртуального окружения

```bash
python3 -m venv venv
```

### Активация виртуального окружения

Для macOS/Linux:

```bash
source venv/bin/activate
```

### Запуск программы

```bash
python main.py
```
